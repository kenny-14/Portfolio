Featured Work

Ball Mill Stress Analysis App
React Native Expo Firebase Documentation Lead

A cross-platform mobile application for Namibian mineral-processing engineers to perform real-time compressive stress analysis on ball mill support structures. The app computes stress using σ = F/A, classifies results against material yield strengths, and stores records in Firebase Firestore with full user authentication.
